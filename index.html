Protocol

Four steps.
Zero intermediaries.

No API keys rotting in your codebase. No invoices at the end of the month. The chain handles it.

01

Register a Model

Developers publish their model on-chain with an IPFS content identifier and a wei-denominated price per inference. Immutable from day one.

02

Pay On-Chain

Users call payForInference() on the contract. The chain validates the exact amount and emits a payment event. No middle layer can intercept.

03

Receive a JWT

A serverless event listener detects the payment confirmation and issues a cryptographically signed, time-bound access token — in under two seconds.

04

Call the API

Pass the JWT in the Authorization header. The gateway validates the token, routes to the container, and returns the model output. Royalties auto-distribute.
